## 遇到的问题与解法（含失败尝试）

1. **LaTeX 装不上（失败尝试 → 换路）**：WSL `sudo -n true` 报"password is
   required"，系统级 `apt install texlive` 走不通。先下载 tectonic 单二进制（用户
   空间）应急，随后用户自行装好 TeX Live 2023（有 pdflatex，无 xelatex/latexmk），
   tectonic 弃用，改用 pdflatex 编译两遍。
2. **Write 工具写不进大文件（失败尝试 → 换路）**：`report.tex`（约 38 KB）单次写入
   连续两次报 `JSON Parse error: Unterminated string`。改用 bash heredoc（引号定界
   'LATEX_EOF'，保证反斜杠字面）分 5 段追加拼接，写成成功。记录此坑：LaTeX/长文
   不要用 Write 一次性灌。
3. **`\tc` 宏嵌套数学模式（自造 bug）**：原定义 `\newcommand{\tc}{$^\circ$C}` 自带
   数学定界符，出现在 `$|\dmax| > 10\tc$` 这类公式内部时提前闭合 `$`，引发
   `Missing $ inserted` 雪崩（log 里 30+ 处）。改为 `\ensuremath{^{\circ}\mathrm{C}}`，
   文本/数学两种上下文都安全。
4. **hyperref 颜色报错**：用了 `blue!55!black` 混色但漏 `\usepackage{xcolor}`，每次
   引用报 `Undefined color`。补上 xcolor（放在 hyperref 前）解决。
5. **sed 反向引用翻车**：修 `ECA\D{}`（`\D` 未定义）时用 `sed 's/ECA\\D{}/ECA\\&D/'`，
   sed 把替换串里的 `&` 当"整个匹配"，把 `\D` 又插回去，变成 `ECA\ECA\D{}D`。改用
   edit 工具精确替换修好。教训：sed 替换文本里有 `&` 时必须转义为 `\&` 或干脆用
   edit 工具。
6. **overfull hbox ×4**（17.1/27.1/3.2/48.7 pt）：Table 1 太宽 → 改 `\footnotesize` 并
   缩短表头；MLP 段落 27 pt → 拆开内联集合数学、加分号让行可断；Declarations 里长
   GitHub URL 48 pt（`weather_prediction_dataset` 整体不可断）→ 局部 `\sloppy`。
   最终 0 overfull。
7. **复现脚本传绝对路径失败（失败尝试 → 换路）**：`"$PY" "$ROOT/$script"` 传
   `/mnt/e/...`，Windows Python 解析成 `E:\mnt\e\...` 报 Errno 2。改为
   `(cd "$ROOT" && "$PY" "$script")` 用相对路径，脚本内加注释说明原因。
8. **复跑后两个非报告文件的差异（非内容差异）**：`delta_t_probe*.csv` 仅行尾
   CRLF↔LF（`tr -d '\r'` 后与 HEAD 完全一致）；`eda_results.json` 统计量全部一致，
   仅 3 处 `"unit": "°C"` 在 cp936 环境下被写成乱码 `??C`（与 R3 记录的 `±` 乱码同类）。
   处置：保留仓库中正确编码的版本（`git checkout --`），编码问题记入本记录，不让
   乱码污染仓库。
9. **一个未经证据支撑的数字被自查拦下（失败尝试）**：fig14 图注初稿写"baseline varies
   from 1.8 to 2.6 °C across stations"，但 per-station zero 的 min/max 没有落到任何
   已提交 CSV（只有 per-station L2 的 min 1.299/max 1.998 有记录）。按"报告数字必须
   与代码输出一致"的红线，删掉该范围改为定性表述"varies substantially"。这条是
   本次自检最大的实际收获：宁可少一个数字，不放追不到出处的数字。
